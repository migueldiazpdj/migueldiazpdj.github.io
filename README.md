# Portfolio terminal

Sitio estático simple para GitHub Pages.

## Publicar cambios

```bash
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/migueldiazpdj/migueldiazpdj.github.io.git
git push -u origin main
```

Después de cada cambio:

```bash
git add .
git commit -m "Update portfolio"
git push
```
